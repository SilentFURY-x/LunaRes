# 🛡️ Panelist Cross-Examination (Q&A Defense Guide)

### Q1: "How do you guarantee the AI isn't hallucinating fake craters or rocks?"
**Answer:**
> *"That is precisely why we refused to build a generic GAN and instead built our **Uncertainty Quantification Engine**. The confidence map analyzes gradient variances across the latent feature space. If an area lacks physical optical cues (like deep shadows), the confidence score plummets to near zero. A scientist never receives raw pixels alone; they receive a co-registered confidence raster so high-risk missions never rely on unverified detail."*

---

### Q2: "How do you handle multi-gigabyte satellite scenes without running out of GPU VRAM?"
**Answer:**
> *"We built an automated **Tiled Inference with Overlap Feathering** pipeline. The backend slices multi-gigabyte GeoTIFFs into 512×512 tiles with a 64-pixel overlap margin. These tiles are distributed across Celery worker queues. During reconstruction, overlapping boundaries are blended using a 2D cosine ramp:
> $$W(x) = 0.5 - 0.5 \cos(\pi x / \text{overlap})$$
> This keeps GPU VRAM constant under 3 GB regardless of whether the input image is 100 MB or 10 GB, while preventing seam artifacts."*

---

### Q3: "What is the difference between your T-GAN model and SwinIR?"
**Answer:**
> *"**T-GAN** is our custom, lightweight model optimized for low-latency inference on lunar panchromatic terrain. It was trained directly on 50 real Chandrayaan-2 TMC-2/OHRC paired scenes to maximize speed and physical feature fidelity.
> **SwinIR** is a heavy Shifted-Window Vision Transformer benchmark. It provides superior perceptual metrics (PSNR/SSIM) at the expense of higher compute time. We integrated both into our unified model registry so operators can toggle between speed and benchmark accuracy."*

---

### Q4: "How does this actually integrate with ISRO pipelines?"
**Answer:**
> *"We implemented an adapter layer adhering strictly to the **ISRO Bhoonidhi REST API contract**. It accepts standard PDS and GeoTIFF inputs, preserves georeferencing metadata (CRS, GSD, sensor IDs, acquisition timestamps), and produces standard Cloud-Optimized GeoTIFF (COG) outputs accompanied by JSON metadata sidecars that can be ingested directly into ISRO's archival nodes."*

---

### Q5: "Why not just use standard bicubic interpolation?"
**Answer:**
> *"Bicubic interpolation simply averages neighboring pixel values. It blurs high-frequency edges, making small boulders and micro-craters invisible. LunaRes reconstructs sharp morphological boundaries learned from actual sub-meter planetary optics, yielding measurable improvements in downstream feature detection."*

---

### Q6: "What happens if a worker fails or model weights are missing?"
**Answer:**
> *"We built self-healing fallbacks at every layer. If GPU weights are unavailable, the model wrapper gracefully engages a deterministic fallback so API pipelines never crash. If a tile task fails in Celery, exponential backoff retries the tile without losing the completed parts of the batch."*
